#Como contribuir
- Siempre trabajando en ramas.
- Los commits deben seguir Conventional Commits
- Todo cambio requiere revision antes del merge
- El trabajo asistido con Claude Code sigue la misma regla: cada tarea va en
  su propia branch (convención `docs/bloque-N-completo`, `chore/...`, etc.),
  nunca commit directo a `main`. El merge final vía PR en GitHub lo hace el
  colaborador humano, no la sesión de Claude Code. Detalle completo del
  protocolo en `CLAUDE.md`.
